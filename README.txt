GEF Research & Development Department Portfolio Website
PHASE 6 FINAL BUILD

This is the final GitHub Pages-ready package for the public English portfolio website of Ghazali Education Foundation — Research & Development Department.

LOCKED MODEL
GitHub Pages + Google Sheets + Google Drive

WHAT THIS WEBSITE DOES
- Shows public portfolio content in professional English.
- Fetches website data from the connected Google Sheet.
- Uses Google Drive links for logo, photos, covers, PDFs, folders, and gallery images.
- Shows only rows where Status = Active.
- Hides Draft and Hidden rows.
- Sorts items by Display Order.
- Converts supported Google Drive file links into public image preview links.
- Provides fallback content so the website does not break if Sheet access temporarily fails.
- Includes WhatsApp order buttons for Publications & Educational Titles.

DEPLOYMENT SUMMARY
1. Extract this ZIP.
2. Upload all files and folders inside this package to the root of your GitHub repository.
3. Go to GitHub repository Settings.
4. Open Pages.
5. Select Deploy from a branch.
6. Select main branch and /root folder.
7. Save.
8. Wait for GitHub Pages to publish the website.

IMPORTANT
Keep the Google Sheet and Google Drive files/folders shared as: Anyone with the link can view.
