DATA UPDATE GUIDE
GEF R&D Portfolio Website

GENERAL RULE
The website is controlled through Google Sheets and Google Drive.
You should not edit code for normal content updates.

STATUS RULE
Active = visible on website
Draft = hidden from website
Hidden = hidden from website

DISPLAY ORDER RULE
Use Display Order numbers to control the order of cards.
Example:
1 appears before 2
2 appears before 3

GOOGLE DRIVE RULE
For images, PDFs, covers, and folders:
1. Upload the file to the correct Google Drive folder.
2. Right-click the file or folder.
3. Click Share.
4. Set access to: Anyone with the link can view.
5. Copy the link.
6. Paste the link into the correct Google Sheet column.
